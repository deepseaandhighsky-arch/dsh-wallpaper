# Project status: v0.3.0-rc.7

DSH Wallpaper is an **MIT-licensed unofficial third-party plugin**. This version is an experimental preview candidate, **not a stable release**. The repository can remain private while publication approval and hardware acceptance are pending.

## Implemented

- Image and video wallpapers stored locally; preferences and named presets.
- Independent UI surface opacity controls, wallpaper blur, frosted surfaces and Windows sidebar positioning fix.
- Reading, Balanced and Immersive presets with custom presets and before/current comparison.
- Chinese and English labels, user-facing diagnostics and a built-in test pattern.
- Dependency-free Node regression checks, source audit and deterministic ZIP creation.

## Evidence and limits

- The v0.3.0-rc.7 candidate passed 52/52 Node tests before the license/metadata-only publication preparation.
- These are source-level and simulated-DOM tests, **not** a full DSH Desktop visual or video performance certification.
- Windows DSH Desktop acceptance for this exact candidate is still pending. macOS and Web have not been certified.
- Recheck GitHub Actions on the exact commit and follow `docs/RELEASE_CHECKLIST.md` before a public launch.
